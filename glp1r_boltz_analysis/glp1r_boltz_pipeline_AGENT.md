## ProLIF Classification

```python
def classify_plip_type(resname):
    name = resname.upper()
    if   name in ("LYS","ARG","HIS"):          return "PiCation"
    elif name in ("ASP","GLU"):                 return "SaltBridge"
    elif name in ("TYR","TRP","PHE"):           return "PiStacking"
    elif name in ("SER","THR","ASN","GLN","CYS","MET"): return "HydrogenBond"
    elif name == "CL":                          return "HalogenBond"
    else:                                       return "Hydrophobic"
```

## PyMOL PML Structure (generated by cluster_dash.py)

```
1. cmd.set_color('hydrogenbond', ...)         # 6 ProLIF colors
2. cmd.set_color('protein_gray', ...)         # receptor base color
3. cmd.set_color('ligand_green', ...)         # ligand color
4. cmd.set_color('elem_N/O/S/...', ...)       # element colors
5. cmd.load('medoid.pdb', 'receptor')
   cmd.remove('receptor and chain L')
   cmd.remove('receptor and not chain R and not chain P')
   cmd.color('protein_gray'), cmd.show('cartoon')
6. cmd.load('medoid_lig.pdb', 'ligand')
   cmd.show('sticks')
7. for each interacting residue:
   cmd.distance('d_{Type}_{RES}{RESID}', 'receptor...', 'ligand...')
   cmd.color('{type}', 'd_...')
   cmd.hide('labels', 'd_...')
8. for each sidechain:
   cmd.select('sc_{chain}_{resid}', ...)
   cmd.show('sticks'), cmd.color('{type}')
9. cmd.color('elem_N', 'all and element N')   # APPLIED LAST
   cmd.color('elem_O', 'all and element O')
10. cmd.orient(), cmd.zoom(), cmd.save()
```

## Gotchas

1. **Chain mapping critical**: Interaction JSON A→PDB R, B→P. Wrong mapping = invisible dashes.
2. **Element color LAST**: PyMOL applies last command first. Must run element override AFTER interaction colors.
3. **Dash labels hidden**: `cmd.hide('labels', 'd_*')` prevents distance numbers from cluttering view.
4. **Boltz frame vs PDB frame**: Centroid analysis must use Boltz centered coordinates.
5. **PLIP JSON key format**: `{prefix}_{ligand}_{seed}_out` — parse seed from trailing `_out` suffix.
6. **Ligand extraction**: Filter HETATM where column 22 = 'L' (chain identifier).
